# v0.27

- PNG／JPEG／PDF出力が失敗する不具合を修正．v0.26で呼び出していた地質解釈線のCanvas再描画関数が実体未定義だったため，出力時にJavaScriptエラーとなっていた．
- 褶曲軸・地質境界・断層などの地質解釈線をPNG／JPEG／PDFへ確実に再描画．
- 「位置・縮尺テンプレート」は位置・Zoom・背景地図・用紙・余白・DPI・固定縮尺のみを扱う仕様へ変更．
- テンプレートを呼び出しても「地点番号を表示」「傾斜角を表示」「走向値を表示」「偏角補正後を使用」「マークサイズ」「重なり回避」「線名表示」などの現在の表示状態は変更しない．
- 旧テンプレートに display 情報が入っていても無視して読み込むため，既存テンプレートをそのまま利用可能．
