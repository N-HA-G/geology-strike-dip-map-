# 走向・傾斜マップ

## Version 0.10.0

Version 0.9.0に，Excelと既存ポイントの地点番号対応，ポイント個別表示ON／OFFを追加しました．

## Excelと既存ポイントの対応

先に地図，GPX，手入力などでポイントを作成できます．

その後Excelを読み込むと，「地点番号」が同じ既存ポイントを自動で探します．

既存ポイントと一致する場合は，Excelの走向・傾斜，測定日，岩種・地層名，面・構造，補足情報をそのポイントへ反映します．

Excelの緯度・経度を空欄にしておけば，既存ポイントの座標をそのまま使用します．

Excelに緯度・経度が入力されている場合は，既存ポイントの座標も更新します．

一致するポイントがない場合は，Excelに緯度・経度があれば新しいポイントとして追加します．

一致するポイントがなく，Excelの緯度・経度も空欄の場合はエラーにします．

## ポイントごとの表示ON／OFF

ポイント一覧に「表示」チェックボックスを追加しました．

チェックありなら地図に表示し，チェックを外すと地図から非表示になります．

ポイントのデータ自体は削除されません．

表示状態は作業JSONに保存されます．

CSVとGeoJSONにもvisible項目を出力します．
