# 走向・傾斜マップ

## Version 0.8.0

Version 0.7.0に，ポイント一覧からの直接編集と一括反映を追加しました．

## 1．ポイント一覧から直接入力

ポイント一覧の以下の項目を，表の中で直接編集できます．

- 地点番号
- 緯度
- 経度
- 入力走向
- 入力傾斜
- 測定日
- 岩種・地層名
- 面・構造
- 補足情報

複数の地点を連続して編集できます．

編集した行は薄い背景色で示されます．

## 2．一覧の変更を一括反映

複数行を編集したあと，

「一覧の変更を一括反映」

を押すと，変更したすべての地点をまとめて反映します．

走向・傾斜はこの時点で再計算され，地図上の記号もまとめて更新されます．

入力エラーがある場合は，全部を反映する前に処理を止めます．

「一覧の変更を元に戻す」を押すと，まだ反映していない表の変更を破棄できます．

## 3．面・構造の種類を手入力化

面・構造の種類は選択式を廃止し，自由入力に変更しました．

例えば以下を自由に入力できます．

- 層理面
- 亀裂
- 節理
- 断層面
- 層面すべり面
- スリッケンライン
- 褶曲軸面
- その他の任意の記載

一覧表からも直接入力できます．

## 4．従来機能

- 地図クリックによるポイント作成
- 走向・傾斜の自動変換
- 複数GPXファイル読み込み
- GPX軌跡表示
- ポイント一覧の並べ替え
- ポイント補足情報
- 走向・傾斜記号のサイズ変更
- 作業状態JSONの保存・読込
- CSV出力
- GeoJSON出力
- PNG出力
- JPEG出力
- PDF出力
- 出力時のスケールバーと北向き方位記号

背景地図には国土地理院の地理院タイルを利用しています．


## 5．未反映の一覧編集も作業JSONへ保存

ポイント一覧で入力途中で，まだ「一覧の変更を一括反映」を押していない内容も，作業状態JSONへ保存します．

JSONを読み込むと，未反映だった行は再び一覧の入力欄へ復元されます．
