# 走向・傾斜マップ

## Version 0.9.0

Version 0.8.0に，Excelテンプレート読込と開発中の簡易パスワード画面を追加しました．

## Excelテンプレート

同梱の `strike_dip_import_template.xlsx` を使えます．

入力項目．

- 地点番号
- 緯度
- 経度
- 走向
- 傾斜
- 測定日
- 岩種・地層名
- 面・構造
- 補足情報

Web画面の「Excelテンプレート読み込み」から，入力済みExcelを読み込めます．複数ファイル同時読込にも対応しています．

Excelの走向・傾斜は，Web上で手入力した場合と同じ規則で自動変換します．

## 開発中の簡易パスワード

`config.js` の `accessPassword` を変更すると，開発中画面のパスワードを変えられます．

初期パスワード．

`fold-dev-2026`

注意．GitHub Pagesは静的サイトです．このパスワード画面は，URLを知った人の偶発的な閲覧を抑えるための簡易ロックです．ソースコードを確認できる人に対する本格的なアクセス制御にはなりません．
