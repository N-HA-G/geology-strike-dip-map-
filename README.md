# 走向・傾斜マップ

## Version 0.5.0

Version 0.4.0を拡張し，GPX読み込み，複数ファイル対応，位置ポイント編集，一覧ソートに対応しました．

## 1．位置だけを先に登録

地図をクリックすると，緯度と経度が入力されます．

走向と傾斜を空欄のまま「ポイントを追加」を押すと，位置だけを登録します．

このポイントは地図上では丸印で表示され，一覧では「未入力」と表示されます．

一覧の「編集」を押すと，あとからN30E，45SEなどを入力できます．保存すると丸印が走向・傾斜記号へ変わります．

## 2．複数GPXファイル読み込み

GPXファイル選択欄では，複数ファイルを同時に選択できます．

### wpt

ウェイポイントを編集可能な位置ポイントとして一覧へ追加します．

### rtept

ルートポイントを編集可能な位置ポイントとして一覧へ追加します．ルート自体も線で表示します．

### trk / trkpt

トラックは軌跡線として地図上に表示します．

trkptは非常に多くなる場合があるため，Version 0.5.0では全trkptをポイント一覧には追加しません．軌跡線を見ながら必要な地点を地図上でクリックして，新しい測定ポイントを作成できます．

## 3．一覧の並べ替え

以下の列をクリックして並べ替えできます．

- No.
- 地点番号
- 状態
- 由来
- 緯度
- 経度
- 入力走向
- 入力傾斜
- 走向方位角
- 傾斜角
- 傾斜方向

同じ列をもう一度押すと，昇順と降順が切り替わります．

## 4．ポイント編集

一覧には以下の操作があります．

- 地図へ．そのポイントまで地図を移動します．
- 編集．地点番号，緯度，経度，走向，傾斜を編集します．
- 削除．そのポイントだけを削除します．

GPX由来の位置ポイントにも，編集から走向・傾斜を追加できます．

## 5．外部出力

CSVとGeoJSONには，手動ポイントとGPX由来ポイントの両方を出力します．

位置だけのポイントでは，走向・傾斜関係の値は空欄またはnullになります．

以下の由来情報も保持します．

- source
- source_file
- source_type
- gpx_time

## 6．PNG画像

現在表示中の地図をPNG画像として出力できます．

画像には以下が含まれます．

- 地理院地図
- 位置ポイント
- 走向・傾斜記号
- GPX軌跡
- スケールバー
- 国土地理院の出典表示

背景地図には国土地理院の地理院タイルを利用しています．
