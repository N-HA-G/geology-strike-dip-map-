# 走向・傾斜マップ

構造地質調査で取得した走向・傾斜と測定地点を，地理院地図上に表示するためのWebアプリです。

## Version 0.0.2

### 実装済み

- Leaflet 1.9.4
- 国土地理院「標準地図」
- 国土地理院「淡色地図」
- 国土地理院「全国最新写真（シームレス）」
- 右上のレイヤーコントロールで背景地図を切替
- 初期表示は千葉県南部
- 初期背景は淡色地図

## 次の予定

Version 0.1 では，緯度・経度と走向・傾斜を手入力し，
地図上に測定地点と走向・傾斜記号を表示する機能を追加します。

## 出典

背景地図には国土地理院の地理院タイルを利用しています。
