# 走向・傾斜マップ

## Version 0.6.0

Version 0.5.0に，作業状態の保存・読込と，複数形式の地図出力を追加しました．

## 1．作業状態の保存と読込

### 保存

「作業状態を保存(JSON)」を押すと，現在の編集途中の状態をJSONファイルとして保存します．

保存対象．

- ポイント一覧
- 地点番号
- 緯度・経度
- 走向・傾斜
- 変換後の走向方位角・傾斜角・傾斜方向
- 並べ替え状態
- 地図の中心座標とズーム
- 背景地図の種類
- GPX軌跡の表示内容

### 読込

保存済みJSONを選択して「作業状態を読込(JSON)」を押すと，再開できます．

これにより，編集途中の状態を後日そのまま再開できます．

## 2．地図としての保存

以下の形式に対応しました．

- PNG
- JPEG
- PDF

出力対象は，現在表示中の地図です．

含まれるもの．

- 地理院地図
- 位置ポイント
- 走向・傾斜記号
- GPX軌跡
- スケールバー
- 国土地理院の出典表示

含めないもの．

- ズームボタン
- 背景切替UI

## 3．従来機能

引き続き以下に対応しています．

- 複数GPXファイルの同時読み込み
- GPXウェイポイントとルートポイントの位置ポイント化
- トラックの軌跡表示
- 位置ポイントへの後からの走向・傾斜入力
- 一覧の並べ替え
- CSV出力
- GeoJSON出力

背景地図には国土地理院の地理院タイルを利用しています．
