# 走向・傾斜マップ

## Version 0.11.0

Version 0.10.0に，現在のポイントから入力用Excelを自動生成する機能と，ユーザー定義の色分け機能を追加しました．

## 推奨ワークフロー

1．GPX，地図クリック等から位置ポイントを作成します．  
2．ポイントへ地点番号を付けます．  
3．「現在のポイントから入力用Excelを作成」を押します．  
4．地点番号と緯度・経度が反映されたExcelを保存します．  
5．Excelで走向，傾斜，測定日，岩種・地層名，面・構造，色区分，補足情報を入力します．  
6．ExcelをWebアプリへ読み込みます．  
7．地点番号が一致する既存ポイントへ情報が反映されます．  

## 自動生成Excel

現在のポイントから生成するExcelには，以下のシートがあります．

- 入力テンプレート
- 色定義
- 説明

入力テンプレートには，現在の地点番号と座標があらかじめ入ります．

## 色分け定義

Web画面で「色区分名」と「色」を自由に追加できます．

例．

- 標準．#111111
- 層理面．#111111
- 亀裂．#d62728
- 層面すべり面．#1f77b4

ポイントごとに色区分を割り当てると，走向・傾斜記号の色へ反映します．

色定義の色を変更すると，同じ色区分に属するポイントの記号をまとめて変更します．

## Excelでの色指定

Excelの「色区分」列で，各ポイントの色区分を指定できます．

「色定義」シートには，

- 色区分
- 色(HEX)

を入力できます．

Excelを読み込むと，色定義もWebアプリへ反映します．

## 保存・出力

色区分と色定義は作業JSONに保存します．

CSVとGeoJSONには，

- color_group
- symbol_color

も出力します．

PNG，JPEG，PDFには設定した色の記号がそのまま出力されます．


## Version 0.11.1．Excelフォント

Webアプリから生成する入力用Excelのフォントを，BIZ UDPGothicに統一しました．

対象シート．

- 入力テンプレート
- 色定義
- 説明

見出し行も同じフォントで太字表示します．

Excelを開くPCにBIZ UDPゴシックがインストールされていない場合は，Excel側で代替フォントが使用される場合があります．
