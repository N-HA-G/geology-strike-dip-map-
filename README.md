# 走向・傾斜マップ

構造地質調査で取得した走向・傾斜と測定地点を，地理院地図上に表示するためのWebアプリです．(基本AIを用いて制作しています．)

## Version 0.1.0

### 今回追加した機能

- 測定地点の緯度・経度を入力
- 走向を方位角（0〜360°）で入力
- 傾斜を0〜90°で入力
- 傾斜方向を方位角（0〜360°）で入力
- 地図上に走向・傾斜記号をSVGで描画
- 傾斜角を記号横に表示
- 複数地点を追加可能
- 地点をクリックすると測定値を表示
- 「全地点を削除」
- 走向と傾斜方向がほぼ直交しているかをチェック

### 入力例

- 緯度：34.910884
- 経度：139.824167
- 走向：30
- 傾斜：45
- 傾斜方向：120

上記は，走向030°，傾斜45°，傾斜方向120°を意味します．

## 注意

Version 0.1.0では，まだ `N30E / 45SE` のような文字表記は解析しません．
まず，数値から記号を正しく描画できることを確認するためのバージョンです．



## 背景地図

国土地理院の地理院タイルを利用しています。
