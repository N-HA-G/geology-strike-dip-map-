# 走向・傾斜マップ

## Version 0.13.0

Version 0.12.0に，地図を画像やPDFとして出力するときの印刷サイズ指定機能を追加しました．

## 1．用紙サイズと向き

以下を選択できます．

- A5
- A4
- A3
- B5
- B4
- Letter

向きは，

- 縦
- 横

を選択できます．

PDFは，この設定をそのまま使って出力します．

## 2．余白

余白をmm単位で指定できます．

印刷時に図の周囲へ余白を残したい場合や，A4横で中央に少しゆとりを持たせたい場合に便利です．

## 3．PNG・JPEGの扱い

PNGとJPEGは本来，紙サイズではなくピクセル数で保存されます．

そのため本アプリでは，

- 選択した用紙サイズ
- 選択した向き
- 指定したDPI
- 指定した余白

から，印刷向けの画像サイズを自動で計算して出力します．

DPIは以下を選択できます．

- 150 dpi
- 200 dpi
- 300 dpi

例えば，

- A4横・300 dpi のPNG
- A3縦・200 dpi のJPEG

のように出力できます．

## 4．PDF

PDFは選択した用紙サイズと向きで直接出力します．

図は指定余白の内側へ自動で収まるように配置します．

## 5．作業JSON

以下の出力設定は作業JSONにも保存します．

- 用紙サイズ
- 向き
- 余白
- 画像DPI

次回読み込み時に，前回の出力設定をそのまま再利用できます．
