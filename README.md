# 走向・傾斜マップ

## Version 0.14.0

Version 0.13相当の印刷サイズ指定機能に加えて，GeoTIFF地図の重ね合わせに対応しました．

## GeoTIFF読み込み

ローカルのGeoTIFFファイルを選択して，地理院地図上へ重ねられます．

複数ファイルの同時読み込みに対応します．

各GeoTIFFについて，

- 表示ON／OFF
- 透明度
- GeoTIFF範囲へズーム
- 個別削除

ができます．

## 対応する座標系

Version 0.14.0では，GeoTIFFの地理座標値がそのまま経度・緯度として扱えるファイルを対象とします．

今回確認したGSJのGeoTIFFは，

- JGD2000
- 緯度・経度
- 約139.7468〜139.9967°E
- 約34.8534〜35.0033°N

であり，この条件に適合します．

UTMや平面直角座標系など，座標値がメートル単位の投影GeoTIFFは，誤配置を防ぐため読み込みを停止します．

## 地図出力

GeoTIFFを表示した状態で，

- PNG
- JPEG
- PDF

を出力すると，GeoTIFFも重ねた状態で画像化されます．

PDFではA5，A4，A3，B5，B4，Letterと，縦／横，余白を選べます．

PNG／JPEGでは，用紙サイズと150／200／300 dpiから印刷向け画像サイズを計算します．

## 作業JSON

GeoTIFF本体は数十MBになる場合があるため，作業JSONへ画像データそのものは埋め込みません．

ファイル名，透明度，表示状態，範囲のメタデータのみ保存します．

作業JSONを読み込んだ後は，必要なGeoTIFFファイルを再度選択してください．
