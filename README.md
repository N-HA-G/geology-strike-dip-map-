# 走向・傾斜マップ

構造地質調査で取得した走向・傾斜と測定地点を，地理院地図上に表示するためのWebアプリです。

## Version 0.0.1

最初の段階として，以下だけを実装しています。

- Leaflet 1.9.4 を利用
- 国土地理院「標準地図」タイルを表示
- 初期表示位置を千葉県南部に設定
- GitHub Pagesで公開可能な静的HTML/CSS/JavaScript構成

## ファイル

- `index.html` : Webページ本体
- `style.css` : 見た目
- `app.js` : 地図処理

## 今後追加予定

1. 標準地図／淡色地図／空中写真の切替
2. 緯度・経度から測定地点を表示
3. 走向・傾斜記号をSVGで描画
4. `N30E / 45SE` 等の表記を自動変換
5. CSV読み込み
6. 入力値の整合性チェック
7. 偏角補正
8. GeoJSON出力
9. QGISとの連携

## 出典

背景地図には国土地理院の地理院タイルを利用しています。
