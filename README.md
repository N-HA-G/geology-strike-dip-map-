# 走向・傾斜マップ

## Version 0.2.0

今回追加した機能．

- 地図クリックで緯度・経度を自動入力．
- クリック地点へ仮ポイントを表示．
- N30E，N30°E，S20W，030などを走向方位角へ自動変換．
- 45SE，45°NWなどを傾斜角と傾斜方向へ自動変換．
- 変換結果を画面上に表示．
- 地図へ追加した地点のポップアップに入力値と変換値を表示．

例．

N30E，45SE．

変換結果．

走向．030°．
傾斜．45°．
傾斜方向．120°．

操作．

1．地図上の測定地点をクリックします．
2．緯度と経度が自動入力され，赤い仮ポイントが表示されます．
3．地点番号，走向，傾斜を入力します．
4．地図に追加を押します．
5．仮ポイントが走向・傾斜記号へ置き換わります．

背景地図には国土地理院の地理院タイルを利用しています．
