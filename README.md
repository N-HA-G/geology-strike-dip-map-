# 走向・傾斜マップ

## Version 0.12.0

Version 0.11.1に，走向・傾斜記号の自動重なり回避と，地図の追加拡大を実装しました．

## 1．走向・傾斜記号の重なり回避

「近接する走向・傾斜マークの重なりを自動回避」をONにすると，画面上で記号同士が重ならないように自動配置します．

重要な点として，実際の測定座標は変更しません．

記号を元の地点からずらした場合は，

- 実測地点に小さな点
- 実測地点から記号までの破線

を表示します．

したがって，地質データの位置情報を保ったまま，地図の可読性だけ改善できます．

## 2．余白調整

「記号間の余白」を0〜40 pxで調整できます．

記号サイズを大きくした場合は，余白も適宜増やすと見やすくなります．

重なり回避設定と余白は作業JSONへ保存します．

## 3．地図の拡大

地図をZoom 22まで拡大できるようにしました．

国土地理院の背景タイルについては，Zoom 18をネイティブ最大ズームとして扱い，Zoom 19〜22ではZoom 18のタイルを拡大表示します．

このため，

- 測定点を細かく分離して確認する
- 近接する走向・傾斜記号を見やすくする

用途には有効ですが，Zoom 19〜22で背景地図そのものの情報量が増えるわけではありません．

## 4．画像・PDF出力

現在の重なり回避状態，補助線，記号サイズは，

- PNG
- JPEG
- PDF

にもそのまま反映されます．

実測地点とずらした記号の関係を保った状態で図として出力できます．
