# 走向・傾斜マップ

## Version 0.7.0

Version 0.6.0に，ポイント補足情報，走向・傾斜記号のサイズ変更，地図出力時の方位記号を追加しました．

## 1．ポイントごとの補足情報

各ポイントに以下を保存できます．

- 測定日
- 岩種・地層名
- 面・構造の種類
- 補足情報の自由記述

面・構造の種類は，層理面，亀裂，断層面，スリッケンライン，その他から選択できます．

補足情報には，露頭の状態，測定条件，写真番号，観察事項などを自由に記録できます．

これらは以下へ保存されます．

- 作業状態JSON
- CSV
- GeoJSON
- ポイント一覧
- 地図上のポイント詳細表示

## 2．走向・傾斜マークの大きさ

走向・傾斜記号の大きさを50〜200％の範囲で変更できます．

変更は地図上のすべての走向・傾斜記号へ反映されます．

この大きさ設定は作業状態JSONにも保存されるため，後日読み込んだ際にも復元されます．

PNG，JPEG，PDF出力にも同じ大きさが反映されます．

## 3．地図出力時の方位記号

PNG，JPEG，PDFを出力するときだけ，地図右上に北を示す方位記号を表示します．

本アプリの地図は回転しないため，画面上方向が北です．

出力画像には以下が含まれます．

- 地理院地図
- 位置ポイント
- 走向・傾斜記号
- GPX軌跡
- スケールバー
- 北向き方位記号
- 国土地理院の出典表示

通常の編集画面では方位記号を表示しないため，操作の邪魔になりません．

## 4．従来機能

- 地図クリックによるポイント作成
- 走向・傾斜の自動変換
- 複数GPXファイル読み込み
- GPX軌跡表示
- ポイント編集
- 一覧の並べ替え
- 作業状態JSONの保存・読込
- CSV出力
- GeoJSON出力
- PNG出力
- JPEG出力
- PDF出力

背景地図には国土地理院の地理院タイルを利用しています．
