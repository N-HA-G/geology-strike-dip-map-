# Version 0.21.0

ポイント一覧に「ポイントの一括表示」を追加しました．

## 一括表示できる項目

- 測定日
- 由来ファイル
- 面・構造
- 岩種・地層名
- 色区分

項目を選ぶと，現在登録されている値が自動的に候補として表示されます．

## 操作

- **該当のみ表示**：選択条件に合う地点だけを地図に表示します．
- **該当を表示**：現在の表示状態を残したまま，該当地点を追加表示します．
- **該当を非表示**：該当地点だけを非表示にします．
- **全て表示**：全地点を表示します．
- **全て非表示**：全地点を非表示にします．

一覧の「表示」チェックボックスとも連動します．

たとえば「測定日 = 2026-09-10」を選んで「該当のみ表示」を押すと，その日の調査地点だけを地図に表示できます．
