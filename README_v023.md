# Version 0.23.0

褶曲軸・地質境界・断層などを地図上へ手動で書き込む「地質解釈線」機能を追加しました．

## 追加内容

- 褶曲軸，背斜軸，向斜軸，地質境界，断層，任意線を手動描画
- 地図クリックで頂点を追加し，「線を確定」で折れ線を保存
- 1頂点戻す／描画取消
- 線名，確度（確認・推定），実線・破線・点線，色，太さ，補足情報を設定
- 線名ラベルの表示切替
- 保存した線の表示／非表示
- 頂点編集：各頂点をドラッグして位置修正
- 線属性の更新，削除，全削除
- 作業JSONへ解釈線を保存・復元
- 解釈線だけをLineString GeoJSONとして出力し，QGISへ直接読み込み可能
- PDF／PNG／JPEG出力にも解釈線をそのまま反映

## 操作

1. 「地質解釈線の書き込み」で線種・線名などを設定します．
2. 「線を描き始める」を押します．
3. 地図上をクリックして頂点を追加します．
4. 「線を確定」で保存します．
5. 線一覧の「頂点編集」を押すと，頂点ハンドルをドラッグして修正できます．

走向・傾斜ポイントGeoJSONと解釈線GeoJSONは別ファイルで出力します．QGISではポイントレイヤとラインレイヤを分けて扱えるため，この方が地質図作成に適しています．
