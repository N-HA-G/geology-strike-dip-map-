# 走向・傾斜マップ

## Version 0.16.0

Version 0.15.0 に，地点番号ラベルの距離調整機能を追加しました．

### 追加機能

- 「表示」欄に「地点番号の距離」スライダーを追加
- 10～70 px の範囲で調整可能
- 地点番号は従来どおり傾斜マークの反対側に配置し，距離だけを変更
- 地図表示，PNG/JPEG/PDF出力へそのまま反映
- 作業JSONへ距離設定を保存・復元
- 位置・縮尺テンプレートにも距離設定を保存・復元
- 旧v0.15以前のJSON／テンプレートは距離31 pxとして互換読込

### 使い方

「表示」→「地点番号の距離」を左へ動かすと走向・傾斜記号へ近づき，右へ動かすと離れます．

初期値は31 pxです．
