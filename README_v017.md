# Version 0.17.0

## A3出力が真っ白になる問題を修正

A3や高DPI出力では，ブラウザのCanvasが巨大になりすぎると，エラー表示なしで真っ白な画像になることがあります．

今回の修正では以下を追加しました．

- PNG/JPEGはCanvasの安全上限を超える場合，実効DPIを自動調整
- A3 900/1200 dpi等で真っ白にならないよう保護
- PDFは巨大なA3ページCanvasを作らず，地図画像をPDFへ直接配置
- Canvas生成に失敗した場合は明示的なエラーメッセージを表示
- 地図タイル・Webフォントの描画待ちを追加
- 出力前にLeafletのサイズを再計算

## 高DPIについて

UI上では従来どおり最大1200 dpiを指定できます．
ただしPNG/JPEGは用紙サイズとの組合せで画像が数億画素になる場合があるため，ブラウザが安全に生成できる実効DPIへ自動的に下げます．

PDFはA3でも巨大Canvasを作らない方式に変更したため，調査用地図の印刷にはPDFを推奨します．
