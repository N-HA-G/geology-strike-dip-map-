# 走向・傾斜マップ Version 0.19.0

Version 0.18.0から，位置・縮尺テンプレートと出力縮尺の扱いを修正しました．

## 変更点

- 「出力縮尺を固定」を追加しました．
- 1:500，1:1000，1:2500などの縮尺分母を数値で指定できます．
- PDF・PNG・JPEG出力時に，指定した用紙サイズ・余白・見出し領域を考慮して，指定縮尺になるよう一時的に地図表示範囲を調整します．
- 出力後は画面の位置・Zoomを元に戻します．
- 作業JSONへ，縮尺固定ON/OFFと縮尺分母を保存します．
- 位置・縮尺テンプレートへ，縮尺固定ON/OFF・縮尺分母・DPIを保存します．
- 保存済みテンプレートの一覧には，縮尺が保存されている場合「1:1000」のように表示します．
- 旧テンプレートはそのまま読み込めます．縮尺情報がない旧テンプレートでは，縮尺固定OFFとして扱います．
- テンプレート名の例から特定の地名を削除し，「全体図_A3_1-1000」のような汎用例へ変更しました．
- 出力タイトルの例も特定地域名を含まない表記へ変更しました．

## 縮尺について

固定縮尺は国土地理院タイルを表示しているLeaflet（Web Mercator）の地上解像度から計算します．通常のフィールドマップ・地質図作成用として使えるよう緯度補正を行っていますが，測量成果としての厳密な縮尺保証を目的とした機能ではありません．

印刷時はPDFビューア側で「実際のサイズ」「100%」を指定し，「用紙に合わせる」はOFFにしてください．
