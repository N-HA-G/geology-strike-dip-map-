# 走向・傾斜マップ v0.18

## 修正内容

PDF出力時に，日本語のタイトル・日付・作成者・出力情報が文字化けする問題を修正しました．

原因は，jsPDFの標準Helveticaフォントで日本語文字列を直接描画していたことです．v0.18では，日本語の見出し部分だけをブラウザCanvasで描画してPNGとしてPDFへ配置します．これにより，Web画面と同じくBIZ UDPゴシック系（利用可能な環境ではBIZ UDPGothic）で表示しつつ，日本語の文字化けを避けます．

また，出力情報に改行が含まれる場合は行ごとに表示し，必要なヘッダ高さも自動で確保します．

A3高解像度出力の白紙化対策（v0.17）もそのまま維持しています．
