# Version 0.22

Excel読み込みの互換性を改善しました．

- Excelシリアル日付（例．46263）を `YYYY-MM-DD` に変換して測定日に反映します．
- 全角数字・全角英字をNFKC正規化してから走向・傾斜を解釈します．例．`２８W` も `28W` として読み込みます．
- `非採用`，`除外` 等の行は，位置情報を残したまま走向・傾斜なしとして扱います．
- 1行に入力エラーがあっても，そこでExcel全体の読込を停止せず，残りの行を続けて読み込みます．
- 読込後に更新地点数，新規地点数，エラー行数を表示します．

今回確認した `布良走向傾斜まとめ.xlsx` では，測定日はExcel内部で数値日付として保存されており，地点19の傾斜が全角数字 `２８W` でした．従来版ではこの地点で処理が停止するため，地点19以降の走向・傾斜が反映されませんでした．
