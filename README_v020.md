# Version 0.20.0

位置・縮尺テンプレートの保存不具合を修正しました．

## 修正内容

- 「現在の位置・縮尺を保存」で保存したテンプレートをブラウザの localStorage に永続保存します．
- 保存直後に再読込して，実際に保存されたか確認します．
- 保存したテンプレートを即座にプルダウンへ選択表示します．
- 旧キー `strikeDipMapViewTemplatesV014` のテンプレートを自動移行します．
- ブラウザの保存領域が使えない場合でも，現在の画面ではメモリ上に保持し，警告を表示します．
- 作業JSONにも `viewTemplates` を含めるため，別PC・別ブラウザへテンプレートを移せます．
- 作業JSON読込時にテンプレートも復元します．
- テンプレート名の例から特定の地名を削除し，「例．全体図_A3」にしました．
- テンプレートには地図中心位置，Zoom，背景地図，用紙，向き，余白，DPI，固定縮尺，走向傾斜記号の表示設定を保存します．
